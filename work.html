RAG application

Local delivery recommendation engine

A RAG-powered recommendation layer for a food delivery platform, grounded in live menu and order data rather than static suggestions.

The problem: generic "popular items" recommendations that ignored what was actually in stock or trending in a given area on a given day.

The build: a retrieval layer indexed against live menu and order data, feeding a ranking step that re-generates suggestions as inventory and demand shift, instead of a fixed list updated by hand.

Automation + RAG

Codebase chat agent

An agentic assistant that lets a team query and reason over a full GitHub repository in natural language.

The problem: onboarding new engineers, or just answering "where does X happen in this codebase," meant grepping through files by hand.

The build: an agent that indexes a repo's structure and history, then answers questions by actually reading relevant files and tracing logic, not guessing from filenames alone.

AI evaluation

Claim verification pipeline

A grounding layer that checks a model's output against a source document and flags claims the document doesn't actually support.

The problem: outputs that sound confident and well-written but quietly say things the source material never claimed.

The build: a checker that breaks a response into individual claims, checks each against the cited source, and flags anything unsupported before it reaches the end user.
